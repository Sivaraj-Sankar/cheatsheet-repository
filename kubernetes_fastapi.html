Kubernetes + FastAPI Deployment Guide

1. Kubernetes Cluster

A Kubernetes cluster consists of:

  • Control Plane – manages the system
  • Worker Nodes – run applications (Pods)

2. Pod (Smallest Unit)

A Pod runs your application container.

apiVersion: v1 kind: Pod metadata: name: fastapi-pod labels: app: fastapi spec: containers: - name: fastapi-container image: yourusername/myfastapi:v1 ports: - containerPort: 8000

3. Service (Stable Access)

Service exposes Pods using labels.

apiVersion: v1 kind: Service metadata: name: fastapi-service spec: selector: app: fastapi ports: - port: 80 targetPort: 8000 type: ClusterIP

4. How Pod & Service Connect

Request → Service → Pod (via label matching)

5. Docker Image Flow

# Build image docker build -t myfastapi:v1 . # Tag for Docker Hub docker tag myfastapi:v1 yourusername/myfastapi:v1 # Push docker push yourusername/myfastapi:v1
FastAPI Code → Docker Image → Registry → Kubernetes pulls image

6. Deployment (Recommended)

apiVersion: apps/v1 kind: Deployment metadata: name: fastapi-deployment spec: replicas: 2 selector: matchLabels: app: fastapi template: metadata: labels: app: fastapi spec: containers: - name: fastapi-container image: yourusername/myfastapi:v1 ports: - containerPort: 8000

7. Versioning Strategy

  • Use Git for code and YAML files
  • Version Docker images (v1, v2, v3)
  • Update image tag in Kubernetes YAML
Code Change → New Image → Update YAML → Deploy

8. Key Concepts Summary

  • Pod = runs your app
  • Service = stable access
  • Deployment = manages Pods
  • Docker image = packaged app
  • Registry = where image is stored
