User → Ingress → Service → Pods (FastAPI instances)

2. Pod (Your FastAPI App)

apiVersion: v1 kind: Pod metadata: name: fastapi-pod labels: app: fastapi spec: containers: - name: fastapi-container image: yourusername/myfastapi:v1 ports: - containerPort: 8000
Pod runs your FastAPI container inside a Kubernetes Node.

3. Service (Stable Access Layer)

apiVersion: v1 kind: Service metadata: name: fastapi-service spec: selector: app: fastapi ports: - port: 80 targetPort: 8000 type: ClusterIP
Service (fastapi-service)
→
Pod A
Pod B

4. Ingress (Real URL Access 🌐)

Ingress exposes your app to the internet using a domain name.

apiVersion: networking.k8s.io/v1 kind: Ingress metadata: name: fastapi-ingress spec: rules: - host: fastapi.local http: paths: - path: / pathType: Prefix backend: service: name: fastapi-service port: number: 80
https://fastapi.local → Ingress → Service → Pods

6. Docker Image Flow

docker build -t myfastapi:v1 . docker tag myfastapi:v1 yourusername/myfastapi:v1 docker push yourusername/myfastapi:v1
FastAPI Code → Docker Image → Registry → Kubernetes pulls image

7. Deployment (Production Way)

apiVersion: apps/v1 kind: Deployment metadata: name: fastapi-deployment spec: replicas: 3 selector: matchLabels: app: fastapi template: metadata: labels: app: fastapi spec: containers: - name: fastapi-container image: yourusername/myfastapi:v1 ports: - containerPort: 8000
Deployment → creates & manages multiple Pods automatically
